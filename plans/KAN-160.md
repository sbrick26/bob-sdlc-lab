## What I understood

The daily dispatch report currently prints customer phone numbers in full. We will mask every phone number in `fieldops/report.py` so the report shows only `415-555-****`. Separately, we will create a new `fieldops/audit.py` module with two wrapper functions — `audit.assign(...)` and `audit.close(...)` — that call the existing `assign.assign_order` and `store.update_order` respectively, then append one structured line to `data/audit.log` recording who performed the action, the timestamp, the order ID, and the change. The log file is append-only; nothing in this ticket may delete or overwrite existing lines. The existing files `fieldops/assign.py`, `fieldops/store.py`, and `fieldops/app.py` are not changed.

---

## Open questions

1. **Should `data/audit.log` be committed to the repo?**
   Default: No — add it to `.gitignore`.

2. **Mask format: should the area code and exchange be preserved (e.g. `415-555-****`)?**
   Default: Yes — keep the first two segments, mask only the last four digits.

---

## Acceptance criteria

- [ ] The daily report shows every customer phone number as `415-555-****`; no full phone number appears in the report output.
- [ ] `audit.assign(who, order_id, crew_id)` calls `assign.assign_order` and appends one line to `data/audit.log` with who, ISO timestamp, order ID, and the crew assigned.
- [ ] `audit.close(who, order_id)` calls `store.update_order` (status → closed) and appends one line to `data/audit.log` with who, ISO timestamp, order ID, and "closed".
- [ ] No customer name or phone number is written to `data/audit.log`.
- [ ] The audit log only grows; existing lines are never changed or deleted.
- [ ] `python -m pytest tests/test_report.py tests/test_audit.py` passes with no failures.

## Risk and compliance

- **PII:** Phone numbers must not appear in the audit log. The mask must be applied before any string is written outside `store.py`.
- **Secrets:** None involved.
- **Data loss:** The audit log is append-only; the work-order CSV is not touched by this ticket.
- **Rollback:** Removing `fieldops/audit.py` and reverting `fieldops/report.py` fully undoes this change.
