## What I understood

The crew assignment service (`fieldops/assign.py`) has no tests, so nobody is confident changing it. This ticket adds a pytest suite that locks in the existing behaviour of `pick_crew`, `crew_load`, and `assign_order` exactly as they stand today. No production code changes. If something looks wrong, it is noted in a comment in the test, not fixed.

---

## Design decisions

1. **Test file location** — `fieldops-repo/tests/test_assign.py`.
   Answer: default. One dedicated file for the assignment rules.

2. **conftest.py** — `fieldops-repo/tests/conftest.py` will redirect `store.ORDERS_FILE` and `store.CREWS_FILE` to temp copies before each test, so the real CSVs are never read or written.
   Answer: default.

3. **Known oddity (missing site)** — `pick_crew` silently skips site rules when `order["site"]` is blank. A test will assert this documented behaviour (falls through to skill fallback) rather than fixing it.
   Answer: default — document, do not fix.

4. **Priority-2 home-crew test** — an additional test covers the priority-2 rule (home crew is chosen only when they also have the required skill).
   Answer: default.

## Acceptance criteria

- `python -m pytest tests/test_assign.py -v` exits green.
- There is a test that asserts the priority-1 rule: the home-crew is picked regardless of skill.
- There is a test that asserts the site rule for priority-2: home-crew is picked only when they have the skill.
- There is a test that asserts the skill-fallback path (no site match → first free crew with the skill).
- There is a test that asserts an order with no site skips site rules and falls through to skill fallback.
- No file under `fieldops/` or `data/` is changed by this ticket.

---

## Test plan

All criteria are verified by `fieldops-repo/tests/test_assign.py`:

| Criterion | Test function |
|---|---|
| Priority-1 home-crew rule | `test_pick_crew_priority1_home_crew` |
| Priority-2 home-crew + skill rule | `test_pick_crew_priority2_home_crew_with_skill` |
| Skill fallback | `test_pick_crew_skill_fallback` |
| No-site falls through to skill fallback | `test_pick_crew_no_site_uses_skill_fallback` |
| Green suite / no data files changed | CI run of `python -m pytest tests/test_assign.py -v` |

`fieldops-repo/tests/conftest.py` wires temp files before each test so the real CSVs are untouched.
