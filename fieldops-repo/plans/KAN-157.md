## 1. Ticket
- **Key:** KAN-157

## 2. What I understood
The crew assignment service (`fieldops/assign.py`) has no tests. Anyone who needs to change it has no safety net. This ticket adds a focused test file that locks in the four observable behaviours described in the ticket: the priority-1 home-crew rule, the site rule, the skill fallback, and the no-site edge case. No production code changes. If anything looks wrong, it is noted in the change log, not fixed.

## 3. Design decisions
1. **Test file name** — asked: use `tests/test_assign.py`. Answer: default. No change to scope.
2. **conftest.py approach** — asked: create/update `tests/conftest.py` with a pytest fixture that redirects `store.ORDERS_FILE` and `store.CREWS_FILE` to temp files. Answer: default. The fixture lives in `conftest.py` so it is available to future test files too.
3. **Observed oddities** — asked: write down anything that looks wrong in `changes/KAN-157.md` only, no `xfail`. Answer: default. Tests only capture actual current behaviour.
4. **Coverage target** — asked: exactly the four "done when" bullets, no extra end-to-end test. Answer: default. Scope is minimal.

## 4. Open questions
None.

## 5. Acceptance criteria
- [ ] `python -m pytest tests/test_assign.py -v` exits 0 with all tests passing.
- [ ] There is a test that calls `pick_crew` with `priority=1` and a matching home-site crew, and asserts that crew is returned (home crew goes first).
- [ ] There is a test that calls `pick_crew` with a site set and `priority` not 1, and asserts only a skill-matching home crew is selected (site rule).
- [ ] There is a test that calls `pick_crew` with no site-matching crew, and asserts the first free crew with the required skill is returned (skill fallback).
- [ ] There is a test that calls `pick_crew` with `site=""` (or absent), and asserts a result is returned without error (no-site edge case).
- [ ] No file under `fieldops/` or `data/` is modified by this change.

## 6. Test plan
All criteria are verified by `fieldops-repo/tests/test_assign.py`:
- Priority-1 rule → `test_pick_crew_priority1_home_crew_goes_first`
- Site rule → `test_pick_crew_priority2_home_crew_needs_skill`
- Skill fallback → `test_pick_crew_skill_fallback`
- No-site edge case → `test_pick_crew_no_site`

The `store` redirect fixture lives in `fieldops-repo/tests/conftest.py` and is used by any test that calls `assign_order` (none required here, but the fixture must not interfere).

Run: `python -m pytest tests/test_assign.py -v`

## 7. Work units
